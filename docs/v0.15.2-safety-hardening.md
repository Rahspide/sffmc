# v0.15.2 — Safety hardening

**Branch:** `release/v0.15.2`
**Goal:** close 4 specific gaps in rule-based detection identified by external audit.

## Definition of terms

- **deny** — block the tool call, no user prompt
- **ask** — require user confirmation via OpenCode permission handler
- **pass** — allow the call
- **anchor** — point in command string where the command word must appear (start of string, after `;`/`&&`/`||`/`|`, after `$(`/backtick, after `sudo`/`env`/`exec` wrappers)
- **normalize** — preprocessing that strips obfuscation before regex matching
- **fail-closed** — error in detection = deny (not pass)

## Acceptance criteria

### P0 #1 — `_CMDPOS` anchoring (Subagent A)

False positives on data-looking-like-commands → 0:
- `git commit -m "rm -rf /"` → pass (data in argument, not a command)
- `grep 'rm -rf /' log.txt` → pass
- `echo "rm -rf /tmp/never"` → pass
- `cat readme.md | grep "delete"` → pass

True positives on actual commands → preserved:
- `rm -rf /` → deny
- `git commit -m "x" && rm -rf /` → deny (second command)
- `sudo rm -rf /` → deny
- `rm -rf "/"` → deny (quoted root)
- `rm -rf "$HOME"` → deny (variable expansion)
- `rm -rf ${HOME}` → deny

### P0 #3 — Windows coverage (Subagent B)

Base 5-7 patterns, default-installed:
- `cmd /c del` → ask
- `Remove-Item -Recurse -Force` → ask
- `icacls ... /grant everyone` → ask
- `taskkill /F` → ask
- `reg delete` → ask
- `format C:` → ask
- `cipher /w` → ask

### P1 #5 — Fail-closed ask (Subagent C)

If `compileRules()`, `parseRules()`, or `match()` throws:
- Old: `log.warn` + return ask default (silent pass)
- New: catch error, return `{ action: 'deny', reason: 'gate_failure: <msg>' }`

If YAML load fails (panic mode already exists) → unchanged: deny-by-default.

### P2 #7 — Normalization (Subagent D)

Before regex matching, normalize input:
- Null bytes (`\x00`) → strip
- ANSI escapes (`\x1b\[...m`) → strip via ECMA-48 regex
- NFKC Unicode normalization → `ｒｍ` → `rm`, etc.
- Line-continuation (`\<newline>`) → strip `\`

Test cases:
- `\x1b[31mｒｍ -rf /\x1b[0m` → deny
- `rm -rf \` + newline + `/` → deny
- `rm -rf /` with embedded null → deny
